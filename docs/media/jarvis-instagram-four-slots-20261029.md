## Slot 3 — Limits

Post ID: jarvis-media-20261029.instagram.3

### Proposed caption

“Saved,” “tested” and “running” need different evidence.

A file can be retained while the intended runtime is unavailable. A check can pass
on a separate CI runner while a platform account remains unverified.

For a clear Jarvis update, name what was observed, where it happened and what
remains unknown. Keep the unfinished task and its checkpoint when execution is
blocked.

A later successful command in that intended environment is needed before calling
it recovered.

Which status word would you want explained in a project update?
