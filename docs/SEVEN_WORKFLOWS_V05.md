# Seven-Workflow Development Gates v0.5
Status: draft PR. No live registrations, remote APIs, model-generated code execution or customer submissions.

1. **GitHub CI** — verify every current branch SHA and negative tests; preserve errors and do not merge without review.
2. **AI builds AI** — generator is allowlisted Python template scaffold; evaluator is static review, not a secure sandbox or substitute for independent security testing.
3. **Hostinger** — proof-of-concept leads are simulated; verify account-specific website builder limitations and separate checkout/webhook hosting.
4. **Social channels** — validate Meta Facebook/Instagram/Threads, LinkedIn and Substack authorization terms before requesting tokens or posting.
5. **Funding** — separate prospective borrower redirects from partner recruitment; refer users to providers for applications; consent and affiliate disclosures.
6. **Revenue** — no claims of actual conversions, payouts or commissions without independently sourced reports; missing figures say unavailable.
7. **Briefing** — 09:30 America/Los_Angeles reports verifiable status and QA/approval queues; no cross-account chat syncing without authorized access.
